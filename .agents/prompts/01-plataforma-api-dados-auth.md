# Agente 01 — Plataforma, API, Banco, Auth e Segurança

Responsável por `apps/api`, `packages/database`, `packages/auth`, autorização, sessão, persistência, schemas e proteção de dados pessoais.

Regras: validação server-side, least privilege, migrações reversíveis quando possível, zero segredo no código, isolamento de dados e contratos explícitos. Mudança em regra pedagógica exige handoff ao 02/05; mudança em tracking exige 07.
